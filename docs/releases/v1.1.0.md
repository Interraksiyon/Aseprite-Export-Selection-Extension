Export a selected area from Aseprite while preserving the original sprite.

### Install

Download **quick-export-selection-1.1.0.aseprite-extension** below. In Aseprite,
open **Edit > Preferences > Extensions > Add Extension** and select the file.
Then use **File > Export > Export Selection**, or assign your own shortcut.
Requires Aseprite 1.3 or later with Lua scripting support.

### Included

- English menus, dialogs, and messages.
- PNG and JPEG export from the active frame; animated GIF export from all frames.
- Rectangular selection cropping with visible layers and supported transparency.
- Remembered export folders, overwrite confirmation, and original document preservation.
- Verified temporary output and backup recovery for failed file replacements.
